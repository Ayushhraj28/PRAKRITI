# PRAKRITI

CIS 300 website project for **Prakriti Innovations**, an agriculture technology startup that uses AI plant disease detection and a smart soil probe to help farmers in India.

Live site: https://ayushhraj28.github.io/PRAKRITI/

- `index.html` – home page
- `css/style.css` – external style sheet
- `images/` – photos used on the site

Leaf photos are from the PlantVillage dataset; the banner and soil probe illustrations were made for this project.
